| 项 | 内容 |

## 1. 摘要

1. **滤波器已由 MATLAB 实跑设计并量化**为 51 抽头、16 bit 整数系数（和为 32768），实测通带纹波 1.42 dB、阻带最差衰减 28.43 dB、−3 dB 点 1311 Hz。
2. **RTL 与 testbench 已在 Vivado 2022.2 上真实编译并仿真通过**：
   - 链路 TB：158 项检查、0 错误，直流扫描最差误差 **2 LSB**（判据 8 LSB），`en` 门控/复位/输出速率全部 0 违规；
   - 滤波器 TB：8 项检查、0 错误，冲激响应与 MATLAB 系数**逐点 0 LSB**，四个频点增益与 MATLAB 相差 **<0.15%**。
3. **MATLAB、Python 定点模型、xsim 三方结果一致**（第 5 节），说明"设计 → 系数 → RTL → 仿真"这条链没有断点。
4. 仿真过程中发现并修复了 **5 个真实缺陷**，其中 2 个是 DUT/RTL 行为问题，2 个是测试方法的假通过，1 个是工具链用法问题（第 6 节）。这部分是本轮仿真的主要增量。

## 2. 验证环境

### 2.1 被测链路

```
clk 256 MHz ──/16──► CLKIN 16 MHz ──► AMC1306M25 (1-bit ΔΣ, DOUT)
                                            │
                                            ▼
                                   sinc3 CIC, OSR = 256
                                            │  62.5 kSPS, 16 bit 有符号
                                            ▼
                                   51-tap FIR 低通
                                            │  62.5 kSPS, 16 bit
                                            ▼
                            valid_pre/data_pre 与 valid_post/data_post
```

- 输出码定义：`code = (ones_density − 0.5) × 65536`，±250 mV 满量程 ↔ ±25600。
- 滤波器群延迟 25 样本 = **0.40 ms**。

### 2.2 激励

不是随机 0/1，也不是方波：`sim/gen/gen_bitstream.py` 按 SBAS734C 建二阶单环 ΔΣ 调制器，
逐 CLKIN 产生真实比特流（密度 `0.5 + VIN/640 mV`、过载 127+1 图样、12 µV 噪声、
4.5 µV 失调、10 µV 斩波纹波），并**预热 8 个窗口后丢弃**，保证写入的每个比特都是稳态。

12 段 × 2048 bit = 24576 bit，覆盖 −FS…+FS、±过载、零漂移。

### 2.3 两个 testbench

| TB | 作用 | 仿真时长 |
|---|---|---|
| `tb_amc1306_sample` | 链路：12 个直流点 + `en` 门控 + 复位 + 输出速率 + FIR 稳态 | 2.92 ms（实测 3 s 跑完） |
| `tb_fir_lpf` | 滤波器：冲激/直流/四个频点正弦/阶跃，最大吞吐（1 样本/周期） | 11.9 µs（2 s） |

## 6. 仿真中发现并修复的问题

这一轮最有价值的部分：**前 4 个问题在纯静态检查/模型验证里都发现不了**。

### 6.1 `en = 0` 时把积分器一起冻结 → 抽取相位永久偏移（DUT 缺陷）

| | |
|---|---|
| 现象 | `en` 拉低 600 个 CLKIN 再恢复后，后续每个采样点最大误差 183 LSB，且模式固定 |
| 根因 | 原 stub 用 `if (en && tick)` 更新积分器与抽取计数器。`en` 低电平期间计数器停走，而比特流继续，恢复后**抽取窗口相对比特流的相位永久偏移 600 bit（mod 256 = 88）**，此后每个窗口都横跨两个调制器窗口 |
| 修正 | 抽取器只在复位时清零，`en` 只门控 `valid`/`data` 输出（`if (tick)`） |
| 修复后 | 恢复瞬间无暂态，误差回到 0~2 LSB |

> 这是会在硬件上真实发生的 bug：使能信号抖动一次，滤波器相位就错一次。`en` 应当只作为输出门控。

### 6.2 冲激测试"假通过"

| | |
|---|---|
| 现象 | `cap[1..5]` 全是 `x`，但检查报 `worst \|err\| = 0`、PASS |
| 根因 | 只发了 1 个冲激样本就 `idle`。valid 门控的 FIR 每个输入才产生一个输出，**后续 0 样本没打进去**，响应根本没被时钟打出来；而 `x` 参与的算术比较恒为假，于是静默通过 |
| 修正 | 冲激后连续送 51+5 个 0，并先断言 `cap_n >= TAPS` |
| 修复后 | 51 个输出逐点等于系数，0 LSB |

> 教训：TB 里"x 参与比较不报错"是假通过的常见来源，关键检查前要显式断言样本数。

### 6.3 比特流发射偏移 1 bit

| | |
|---|---|
| 现象 | 段 0 的稳态值出现 +126 LSB 的系统偏差，且只出现在特定窗口 |
| 根因 | TB 在第一个 CLKIN 上升沿发的是 `bit_mem[1]`（`bit_cnt` 先自增再取值），DUT 的第一个 256 bit 窗口因此偏移 1 bit，窗口边界上的 1 被算到相邻窗 |
| 修正 | 改为发 `bit_mem[bit_cnt]` 后自增，使 DUT 首窗与生成器首窗严格对齐 |
| 修复后 | 所有窗口逐点吻合 |

### 6.4 调制器启动暂态污染首段

| | |
|---|---|
| 现象 | 段 0 前两个窗口的实际 1 的个数为 29（其余为 28），对应 +126 LSB |
| 根因 | 调制器从 `v1 = v2 = 0` 起步，前 1~2 个窗口尚未建立正确密度；Python 校验当初把这几窗当作"建立期"跳过了，所以没暴露 |
| 修正 | 生成器预热 8 个窗口后丢弃（`--warm-bits 2048`），写入文件的每个比特都是稳态 |
| 修复后 | 全部 96 个窗口逐点精确（含此前被跳过的窗口） |

### 6.5 工具链：xsim 不接受绝对路径的 `-testplusarg`

| | |
|---|---|
| 现象 | `xsim tb --testplusarg "MEM=F:\...\scenario.mem"` 直接打印 usage 退出，报 `Expected a switch but found F` |
| 根因 | xsim 2022.2 的参数解析把 `MEM=F:` 之后的内容当成新开关 |
| 修正 | 把 `scenario.mem` 复制到 xsim 运行目录，TB 回退到默认文件名；`run_xsim.ps1` 自动完成 |
| 附带 | 原来的 `run_xsim.bat` 在 `xvlog` 之后静默退出（LF 换行 + 标签跳转问题），改为 `.ps1` 承载逻辑，`.bat` 只做一行转发 |

## 7. 指标达成情况与局限

### 7.1 达成

| 要求 | 结果 | 判定 |
|---|---|---|
| 低通，通带 1 kHz | 1 kHz 处 −1.42 dB | ✔ 通带内（纹波 1.42 dB） |
| 低通，阻带 2.5 kHz | 2.5 kHz 起 ≥28.4 dB | ✘ 未达常规 50 dB（见下） |
| 50 阶（51 抽头） | 51 抽头 | ✔ |
| 由 MATLAB 生成 coe | `firpm` 实跑，`.coe`/`.vh`/响应图同源 | ✔ |
| 输出滤波前后采样变化 | 4 kHz: 24918 → 940 LSB（−28.5 dB）；阶跃 0.82 ms 平滑 | ✔ |

### 7.2 为什么 51 抽头达不到 50 dB

过渡带 1→2.5 kHz 只占 Fs 的 **2.4%**。Kaiser 估算 `N ≈ (A−8)/(2.285·Δω)`：

- Δω = 2π·1500/62500 = 0.1508 rad/sample；
- 要 A = 50 dB → N ≈ **122 抽头**。

51 抽头的理论上限就在 28~30 dB 一带，**这不是实现问题，是抽头数与采样率的物理约束**。

### 7.3 两个可选改法

| 改法 | 改动量 | 预期 |
|---|---|---|
| `Order = 122` | `amc1306_lpf_design.m` 改一个数，重跑生成 `.coe` | 50 dB 阻带，通带纹波 ≈1 dB，乘法器翻 2.4 倍 |
| 先 /4 抽取到 15.625 kSPS 再滤 | 链路加一级降采样 + 滤波器按 15.625 kSPS 设计 | 51 抽头即可 ~78 dB（Kaiser），乘法器少 4 倍，是电流环更常见的做法 |

### 7.4 另一项工程代价：相位滞后

51 抽头、25 样本群延迟，在 1 kHz 处带来 **144°** 相位滞后（`2π·f·τ = 2π·1000·0.4 ms`）。
再加上 sinc3 自身约 24 µs 的延迟，整条采样链路在 1 kHz 处约 **153°** 滞后。若电流环带宽
要接近 1 kHz，这个滞后会直接吃掉相位裕度——设计环路时要把滤波器延迟算进去，或者把
滤波器的通带边缘做得更高、抽头更少。

### 7.5 未覆盖

- **综合与时序**：只做了行为仿真，没有跑综合/实现，未验证 51 乘法器在目标器件上的时序收敛
  与资源占用（实际会用 FIR Compiler IP 替换 `fir_lpf.v`）；
- **FIR Compiler IP 本身**：`fir_lpf.v` 是行为参考实现，IP 的位真行为（Rounding/Saturation、
  fractional bits 设置）未在仿真中验证，只给了配置说明；
- **AMC1306 模拟侧**：失调/增益温漂、斩波纹波只按典型值建模，未做最坏情况分析；
- **多比特量化与舍入策略**：当前是截断（`>>>15`），若改用四舍五入，直流与低频结果会有 ±0.5 LSB 的差别。

